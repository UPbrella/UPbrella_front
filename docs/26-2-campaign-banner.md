# 배너·스탬프 화면

백엔드 #524의 배너·캠페인 API를 먼저 배포합니다. 배너는 홈 헤더 아래에만 노출하며 소개·지도·로그인·관리자 화면에는 표시하지 않습니다. 관리자에서 이미지·링크·활성·노출 기간·순서를 관리합니다.

스탬프 페이지는 로그인 후 잔액/미션과 설문을 표시하고, 관리자는 활성 여부/반납 기준 및 지급 CSV를 관리합니다. 캠페인은 기본 비활성이며 이 PR은 활성화하지 않습니다. 모바일 하단 메뉴는 실제 높이만큼 공간을 확보하고 관리자·로그인·대여·반납 폼에서는 숨깁니다.

QR은 최신 develop에 있는 /qr-scan을 사용합니다. QR·GA·새 아이콘 구현을 복제하지 않습니다. 예시 배너는 개발 DB에만 등록된 콘텐츠이며 레코드/업로드 파일을 코드에 하드코딩하지 않습니다.
